Nirmala Multispeciality Hospital 🏥❤️

Compassionate Care, Advanced Clinical Excellence

A modern, responsive tertiary healthcare and hospital web application featuring clinical department explorers, filterable specialist doctor profiles, preventive health checkup packages in ₹, interactive OPD/video appointment booking, patient wellness guides, and 24/7 emergency helplines.

🌐 Live Demo: https://roshikosuru-dot.github.io/Hospital/

📖 Overview

Nirmala Multispeciality Hospital is a self-contained, single-page healthcare web application designed with a clean clinical teal, mint, and crisp white palette. Built using semantic HTML5, Tailwind CSS, and Vanilla JavaScript, it provides patients and families with fast access to emergency contacts, specialist consultations, diagnostic services, and preventive health packages across desktop, tablet, and mobile viewports.

✨ Key Features

24/7 Emergency Helpline Bar & Sticky Navigation:

One-tap tel: links for the 24/7 Trauma & Ambulance Desk (+91 866 248 1108), State Ambulance (108), National Emergency (112), 24/7 Blood Bank, and Pharmacy.

Sticky header with a custom medical cross & ECG heartbeat SVG emblem and quick Book Appointment CTA.

Hospital Overview & Accreditations:

Highlights NABH Accreditation, NABL Certified Labs, key capacity metrics (350+ Beds, 85+ Specialist Doctors, 24/7 Cath Lab & ICU, 50+ Insurance & TPA), and cashless TPA / Dr. YSR Aarogyasri support.

Interactive Clinical Departments:

Covers 8 core specialities (Cardiology, Neurology, Orthopaedics & Joint Replacement, Pediatrics & Neonatology, Obstetrics & Gynaecology, General & Laparoscopic Surgery, Gastroenterology, and Critical Care & Emergency Medicine).

Includes a Facilities & Scope modal detailing treated conditions and clinical infrastructure, plus one-click specialist filtering.

Filterable & Searchable Specialist Doctor Profiles:

Displays specialist profiles with qualifications (MBBS, MD, DM, MS, MCh, DNB), spoken languages, OPD timings, consultation fees in ₹ (₹600–₹900), and custom SVG avatars.

Clicking Book Consultation automatically scrolls to the appointment form and pre-selects the chosen department and specialist.

24/7 Clinical Services & Preventive Health Packages (₹):

Showcases round-the-clock Emergency, NABL Labs, 3T MRI & 128-Slice CT, 24/7 Pharmacy, Dialysis, and Physiotherapy services.

Features 3 Master Health Checkup packages (Basic Wellness Check ₹1,499, Comprehensive Heart & Diabetes Profile ₹3,499, and Executive Full Body Checkup ₹5,999) with one-click package pre-fill.

Interactive Appointment Booking & Confirmation:

Accessible form supporting In-Person OPD and Video Consultations, dynamic department-to-doctor dropdown filtering, date and time-slot selection, and an instant Appointment Confirmation Modal with a unique reference ID (NMH-2026-XXXX).

Patient Education Hub & Location Map:

Interactive wellness guides (Heart Health & BP Management, Diabetes Prevention Tips, Monsoon & Seasonal Immunity), expandable patient FAQs, and a custom SVG location map of MG Road & Benz Circle, Vijayawada.

🛠️ Tech Stack

Markup: Semantic HTML5

Styling: Tailwind CSS (via CDN with custom tealMed, mintCare, and urgentRed theme tokens)

Typography & Icons: Google Fonts (Plus Jakarta Sans & Inter) + Font Awesome 6 + Custom Inline SVGs

Interactivity: Vanilla JavaScript (ES6+)

🚀 Getting Started

Clone the repository:

git clone https://github.com/roshikosuru-dot/Hospital.git


Run locally:
Open index.html directly in any modern web browser, or launch it using the VS Code Live Server extension.

Deploy via GitHub Pages:
Ensure index.html is in the root of your main branch and enable GitHub Pages in repository settings.
